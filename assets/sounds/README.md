# Sound Effects Directory

Place your sound effect files here:

## Required Files:
- `shoot.mp3` - Player shooting sound
- `explosion.mp3` - Enemy destruction sound
- `hit.mp3` - Player taking damage sound
- `powerup.mp3` - Power-up collection sound
- `coin.mp3` - Coin/currency collection sound
- `click.mp3` - Button click sound
- `purchase.mp3` - Shop purchase sound
- `background.mp3` - Background music (looping)

## Format:
- MP3 format recommended for best browser compatibility
- Keep file sizes reasonable (< 100KB for sound effects, < 2MB for background music)

## Note:
If files are missing, the game will work silently without errors.
